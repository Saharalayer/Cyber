# SaharaLayer | صحراء لاير — النسخة المحلية الأولى

هذه نسخة أولية للتجربة على جهازك، مبنية بـ HTML وCSS وJavaScript فقط. لا تحتاج إلى تثبيت Node.js أو قاعدة بيانات.

## تشغيلها على Windows 11 (واجهة فرنسية)

1. فك ضغط `SaharaLayer-local.zip` في مجلد يسهل الوصول إليه، مثل `Documents`.
2. افتح المجلد `SaharaLayer-local`.
3. انقر مرتين على `index.html`. ستفتح المنصة في المتصفح.
4. إذا لم تظهر الخطوط كما هو متوقع، تأكد من اتصال الإنترنت لأن الخط العربي يُحمّل من Google Fonts. ستظل الصفحة قابلة للاستخدام دون ذلك.
5. جرّب «المسارات التكوينية»، وافتح وحدة، ثم اضغط «اختبر فهمك». التقدم محفوظ محليًا في المتصفح.

## الملفات

- `index.html`: بنية الصفحات.
- `style.css`: الهوية البصرية والتصميم المتجاوب.
- `app.js`: الوحدات والاختبارات وحفظ التقدم محليًا.
- `assets/logo-saharalayer.jpg`: الشعار الذي زودتني به.

## ما يعمل في هذه النسخة؟

- واجهة عربية RTL متجاوبة.
- ست وحدات تعليمية أولية.
- اختبارات تجريبية وتفسير للإجابات.
- حفظ التقدم والنتائج في `localStorage` بالمتصفح نفسه.
- صفحة تقدم وصفحة تعريف بالمبادرة.

## حدود مهمة قبل النشر

هذه **نسخة تجريبية محلية وليست منصة إنتاجية**:
- لا يوجد تسجيل دخول أو حسابات مستخدمين حقيقية.
- لا توجد قاعدة بيانات أو مزامنة بين الأجهزة؛ البيانات محفوظة في المتصفح الحالي ويمكن أن تختفي عند مسح بياناته.
- لا يوجد إصدار شهادات رسمية. لا تستخدم نتائج هذه النسخة كاعتماد مهني.
- المحتوى توعوي عام وليس تدقيقًا أمنيًا متخصصًا.
- لم تُضف لوحة إدارة أو حماية خادمية أو سياسة خصوصية تشغيلية بعد.
- لا تضع بيانات حقيقية حساسة أو كلمات مرور حقيقية في النسخة التجريبية.

## الخطوة التالية المقترحة

بعد مراجعة التصميم والمحتوى محليًا، ننتقل إلى نسخة متصلة بخلفية آمنة: مصادقة، قاعدة بيانات، صلاحيات خادمية، إدارة الدورات، اختبارات مصححة من الخادم، وتدابير حماية وخصوصية مناسبة قبل فتح التسجيل العام.
